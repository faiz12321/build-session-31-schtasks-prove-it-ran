Common mistakes

  1. Believing "Attempted to run". /run requests a run; it does not confirm the action finished. Check the run time, wait for completion, then inspect the result and output.
  2. Assuming relative paths start at the script. The practice task has no working directory set. Use explicit paths or deliberately set and check the working folder in a real script.
  3. Stopping at Last Result 0. The tiny sample reports its final command result. A more complex script can report success even when an earlier step failed. Check the actual output too.
  4. Leaving practice tasks behind. A made-up daily task keeps firing every day. Delete it when you are done, like the last step does.
  5. Replacing an existing task. Do not add /f to task creation. The setup must pass first; if Windows asks to replace anything, answer N and stop.

Frequently asked questions

What does Last Result 1 actually mean?

Last Result is the task result reported by the scheduler. For the tiny batch script in this recording, the final echo command failed and the result was 1. Do not interpret every nonzero task result using this example; check the task action and that program's exit-code rules.

Why not just set the task's Start In folder?

schtasks /create has no direct working-directory flag. The Task Scheduler app or an XML task definition can set it. For this local practice script, cd /d "%~dp0" steps into the script folder. It is not a universal fix for network paths, permissions or a failed cd command.

Does this work on Windows 10 and 11?

The lesson uses Windows built-in schtasks and cmd.exe. It was recorded on a GitHub-hosted Windows machine, not separately tested on every Windows 10 and 11 edition or language. Labels and dates can differ.

Where does the task appear in the Task Scheduler app?

Open taskschd.msc and look in the top Task Scheduler Library folder. The recording used a task called Lesson31Demo and deleted it afterwards; yours will sit under whatever name you choose.

Can I schedule it for every hour instead of every day?

Yes: /sc hourly instead of /sc daily, and drop /st if you do not care when it starts. Everything else in this lesson - the proof steps and the folder fix - stays the same.
